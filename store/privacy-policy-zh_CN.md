# 隐私政策 — 查找正在播放声音的标签页

**更新日期：** 2026年9月20日

本政策说明 Chrome 与 Firefox 扩展 **「查找正在播放声音的标签页」**（Find Tab Playing Sound，下称「本扩展」）如何处理信息。

## 谁提供本扩展

本扩展由 **PeterShift** 发布。  
联系方式：**petershift.dev@gmail.com**

## 本扩展做什么

本扩展会把浏览器切换到下一个正在播放声音的打开标签页。可以通过工具栏图标或键盘快捷键触发。

## 本扩展会访问哪些数据

为了找到正在播放声音的标签页，本扩展**只在浏览器内**查看某个打开的标签页当前是否有声（`audible`）。为了激活该标签页，它还可能使用标签页标识符和窗口标识符。本扩展**不**申请 `tabs` 权限，因此不能读取标签页的网址、标题或网站图标。

本扩展**不**读取网页内容。

## 我们不收集什么

本扩展**不会**：

- 收集姓名、电子邮箱、账号数据或其他个人信息；
- 保存标签页网址、标题或浏览历史；
- 向开发者运营的服务器发送任何数据；
- 使用分析、广告、崩溃报告或 Cookie；
- 向第三方出售或共享用户数据。

没有开发者后台，也不需要用户账号。

## 信息如何使用

标签页信息只在跳转到下一个有声标签页所需的时间内保留在内存中（包括在内存里对有声标签页做的一次短暂循环）。该操作结束，或后台进程 / 事件页停止时，这些信息即被丢弃。为此不会把任何内容写入扩展存储、磁盘或网络。

## 权限

| 权限 | 为何申请 |
| --- | --- |
| 未声明任何权限 | 本扩展不声明任何额外权限。查找有声标签页并切换过去不需要 `tabs` 权限。 |

## 远程代码

本扩展只运行随 Chrome Web Store 或 Firefox Add-ons 软件包提供的本地文件。它不会下载或执行远程 JavaScript。

## 儿童

本扩展并非面向儿童，也不会在知情的情况下收集任何人（包括儿童）的数据。

## 欧洲经济区和加利福尼亚

本扩展不收集个人数据，因此不出售个人信息，也不在服务器上处理个人数据。在浏览器中安装本扩展由 Google 或 Mozilla 按其自身政策处理。

## 变更

如果数据处理方式发生变化，本政策会更新，并且会在发布该版本之前更新 Chrome Web Store 和 Firefox Add-ons 上的隐私披露。
