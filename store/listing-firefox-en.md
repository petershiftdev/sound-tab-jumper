## Product details

**Name (max 50 characters):**
```
Find Tab Playing Sound
```

**Summary (max 250 characters):**
```
Find which tab is playing audio and switch to it. Click or shortcut to cycle sound tabs.
```

**Description:**
```
Find Tab Playing Sound finds the tab that is currently playing audio and switches to it — including in another Firefox window. Click the toolbar icon or press Ctrl+Shift+S (Cmd+Shift+S on Mac). If several tabs are playing sound, each press jumps to the next one, then back to where you started.

How to use
• Click the extension icon in the toolbar.
• Or press Ctrl+Shift+S (Cmd+Shift+S on Mac). You can change the shortcut at about:addons → Manage Extension Shortcuts.

What it does
• Looks for other open tabs that are currently audible (not the tab you are already on).
• Activates that tab and focuses its window.
• If several tabs are playing sound, each click or shortcut press jumps to the next one, then back to the tab you started from. After that, the cycle starts over.
• If no other tab is playing sound, the click or shortcut does nothing.

What it does not do
• It does not mute, pause, or control media players.
• It does not collect, store, or send your browsing data.
• It does not require an account and has no ads or analytics.

Permissions
The add-on does not request extra Firefox permissions. It only checks, in the browser, which open tabs are currently playing sound, then switches to the next one. Tab identifiers are kept in memory for that action and are not saved or transmitted.
```

**Category:** Tabs
