Privacy Policy — Find Tab Playing Sound

Last updated: 20 September 2026

This policy describes how the Chrome and Firefox extensions Find Tab Playing Sound (“the Extension”) handle information.

Who provides the Extension

The Extension is published by PeterShift.
Contact: petershift.dev@gmail.com

What the Extension does

The Extension switches the browser to the next open tab that is currently playing sound. You can trigger this with the toolbar icon or with the keyboard shortcut.

Data the Extension accesses

To find tabs that are playing sound, the Extension reads, in the browser only, whether an open tab is currently audible (audible). It may also use the tab identifier and window identifier so it can activate that tab. The Extension does not request the tabs permission, so it cannot read tab URLs, titles, or favicons.

The Extension does not read the content of web pages.

What we do not collect

The Extension does not:

  • collect names, emails, account data, or other personal information;
  • store tab URLs, titles, or browsing history;
  • send any data to a server operated by the developer;
  • use analytics, advertising, crash reporting, or cookies;
  • sell or share user data with third parties.

There is no developer backend and no user account.

How information is used

Tab information is kept in memory only for as long as needed to jump to the next audible tab (including a short in-memory cycle of audible tabs). It is discarded when that action finishes or when the background worker or event page stops. Nothing is written to extension storage, disk, or the network for this purpose.

Permissions

PermissionWhy it is requested
None declaredThe Extension does not declare any extra permissions. Finding audible tabs and switching to them does not require the tabs permission.

Remote code

The Extension runs only the local files shipped in the Chrome Web Store or Firefox Add-ons package. It does not download or execute remote JavaScript.

Children

The Extension is not directed at children and does not knowingly collect data from anyone, including children.

European Economic Area and California

The Extension does not collect personal data, so it does not sell personal information and does not process personal data on a server. Installing the Extension in the browser is handled by Google or Mozilla under their own policies.

Changes

If data practices change, this policy will be updated and the Chrome Web Store and Firefox Add-ons privacy disclosures will be updated before that version is published.

Contact

Questions about this policy: petershift.dev@gmail.com

Расширение выполняет только локальные файлы из пакета Chrome Web Store или Firefox Add-ons. Оно не загружает и не выполняет JavaScript из сети.

Хто надає Розширення

Розширення публікує PeterShift.
Контакт: petershift.dev@gmail.com

Що робить Розширення

Розширення перемикає браузер на наступну відкриту вкладку, у якій зараз відтворюється звук. Це можна зробити піктограмою на панелі інструментів або комбінацією клавіш.

Які дані бачить Розширення

Щоб знайти вкладки зі звуком, Розширення лише в браузері дивиться, чи відтворює відкрита вкладка звук (audible). Щоб перемкнутися, воно може використовувати ідентифікатор вкладки та вікна. Дозвіл tabs Розширення не запитує, тому не читає URL, заголовки й піктограми вкладок.

Розширення не:

  • збирає імена, адреси електронної пошти, дані облікових записів та інші персональні відомості;
  • зберігає URL вкладок, заголовки чи історію перегляду;
  • надсилає дані на сервер розробника;
  • використовує аналітику, рекламу, звіти про збої або файли cookie;
  • продає дані користувачів і не передає їх третім сторонам.

У розробника немає власного сервера, обліковий запис у розширенні не потрібен.

Як використовуються відомості

Відомості про вкладки тримаються лише в оперативній пам’яті на час переходу до наступної вкладки зі звуком (включно з коротким циклом таких вкладок у пам’яті). Після дії або зупинки фонового процесу їх відкидають. Для цієї мети нічого не записується у сховище розширення, на диск і в мережу.

Дозволи

Не запитуютьсяРозширення не оголошує додаткових дозволів. Щоб знайти вкладки зі звуком і перемкнутися на них, дозвіл tabs не потрібен.

Віддалений код

Розширення виконує лише локальні файли з пакета Chrome Web Store або Firefox Add-ons. Воно не завантажує і не виконує JavaScript з мережі.

隐私政策 — 查找正在播放声音的标签页

更新日期：2026年9月20日

本政策说明 Chrome 与 Firefox 扩展 「查找正在播放声音的标签页」（Find Tab Playing Sound，下称「本扩展」）如何处理信息。

谁提供本扩展

本扩展由 PeterShift 发布。
联系方式：petershift.dev@gmail.com

本扩展做什么

本扩展会把浏览器切换到下一个正在播放声音的打开标签页。可以通过工具栏图标或键盘快捷键触发。

本扩展会访问哪些数据

为了找到正在播放声音的标签页，本扩展只在浏览器内查看某个打开的标签页当前是否有声（audible）。为了激活该标签页，它还可能使用标签页标识符和窗口标识符。本扩展不申请 tabs 权限，因此不能读取标签页的网址、标题或网站图标。

本扩展不读取网页内容。

我们不收集什么

本扩展不会：

  • 收集姓名、电子邮箱、账号数据或其他个人信息；
  • 保存标签页网址、标题或浏览历史；
  • 向开发者运营的服务器发送任何数据；
  • 使用分析、广告、崩溃报告或 Cookie；
  • 向第三方出售或共享用户数据。

没有开发者后台，也不需要用户账号。

信息如何使用

标签页信息只在跳转到下一个有声标签页所需的时间内保留在内存中（包括在内存里对有声标签页做的一次短暂循环）。该操作结束，或后台进程 / 事件页停止时，这些信息即被丢弃。为此不会把任何内容写入扩展存储、磁盘或网络。

权限

权限为何申请
未声明任何权限本扩展不声明任何额外权限。查找有声标签页并切换过去不需要 tabs 权限。

远程代码

本扩展只运行随 Chrome Web Store 或 Firefox Add-ons 软件包提供的本地文件。它不会下载或执行远程 JavaScript。

儿童

本扩展并非面向儿童，也不会在知情的情况下收集任何人（包括儿童）的数据。

欧洲经济区和加利福尼亚

本扩展不收集个人数据，因此不出售个人信息，也不在服务器上处理个人数据。在浏览器中安装本扩展由 Google 或 Mozilla 按其自身政策处理。
