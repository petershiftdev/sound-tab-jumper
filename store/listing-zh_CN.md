## Сведения о продукте

**Язык:** 中文（简体）

**Название (до 45 символов):**
```
查找正在播放声音的标签页
```

**Краткое описание (из расширения; до 132 символов):**
```
查找正在播放音频的标签页并切换过去。点击图标或按快捷键，可在有声音的标签页之间循环。
```

**Подробное описание:**
```
「查找正在播放声音的标签页」会找到当前正在播放音频的标签页并切换过去，包括另一个 Chrome 窗口中的标签页。点击工具栏图标，或按 Ctrl+Shift+S（Mac 上为 Cmd+Shift+S）。如果有多个标签页在播放声音，每按一次就跳到下一个，然后回到开始的位置。

如何使用
• 点击工具栏上的扩展图标。
• 或按 Ctrl+Shift+S（Mac 上为 Cmd+Shift+S）。可在 chrome://extensions/shortcuts 更改快捷键。

扩展会做什么
• 查找其他当前有声的打开标签页（不是你当前所在的标签页）。
• 激活该标签页，并把其所在窗口放到前台。
• 如果有多个标签页在播放声音，每次点击或按快捷键都会跳到下一个，然后回到开始时的标签页。之后循环重新开始。
• 如果没有其他标签页在播放声音，点击或快捷键不会有任何效果。

扩展不会做什么
• 不会静音、暂停或控制媒体播放器。
• 不会收集、保存或发送浏览数据。
• 不需要账号，没有广告，也不使用分析。

权限
本扩展不申请额外的 Chrome 权限。它只在浏览器内查看哪些打开的标签页正在播放声音，然后切换到下一个。标签页标识符仅在这次操作期间保留在内存中，不会保存，也不会发送出去。
```
